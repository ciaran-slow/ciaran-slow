## Selected Project

### HiddenGemz – Local Discovery Platform

HiddenGemz is a full-stack web application that enables users to discover, share, and save local venues such as cafés, bars, and restaurants. The platform is built around community-driven content and location-based discovery.

The project was developed collaboratively during the Dev Academy Aotearoa programme.

**Key Features**
- Discover and browse local venues
- Search and filter by location and attributes
- Create and share venue listings with images and tags
- Save favourites and follow other users
- Interactive map integration
- Secure authentication via Auth0

**Tech Stack**  
React · TypeScript · Node.js · Express · PostgreSQL · Tailwind CSS
